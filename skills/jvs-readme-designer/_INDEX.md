# jvs-readme-designer

> 像产品官网那样设计 README 的 Skill。本目录结构或子文件职责变化时，必须更新此文件。

## 职责

为开源项目设计 product-marketing-grade 的 README，支持中英双语，输出图片任务清单，避免常见反模式。

## 文件清单

- `SKILL.md` — Skill 主入口，定义 5 阶段流程（SCAN → ⛔ INTERVIEW → ⛔ ARCHETYPE → DRAFT → ⛔ REVIEW）+ 三维正交参数 + scope-out
- `EXTEND.md` — 用户偏好持久化模板（默认 archetype / 双语策略 / emoji 风格 / 信任信号阈值）
- `_INDEX.md` — 本索引

## 子目录

- `references/` — 设计参考库（principles / interview / answer-map / archetypes / tagline / sections / trust / bilingual / image / anti-patterns / domestic / scope-out / templates）
