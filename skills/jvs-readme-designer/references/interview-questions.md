# 访谈问题清单

## 使用规则

1. **先扫码后提问**：SCAN 阶段已经从代码识别的信息（项目名/语言/类型/已有资产/i18n 状态）**不要再问**
2. **批量问而不是单问**：用 AskUserQuestion 一次提 3-4 个，每个问题给 2-4 个候选 + Other
3. **数量动态、不固定**：`--quick` 上限 5 个，`--full` 上限 7 个；下限 0 个（用户选跳过 / SCAN 已能完整推断）
4. **进入访谈前必须先开场分流**（详见 SKILL.md §2.1）：让用户三选一——"答几个" / "只答最关键 1-2 个" / "全用默认跳过"
5. **只问真实关键的事**：不影响输出形态的问题不要问
6. **每个 single/multi-select 必须含"全用默认"选项**：用户随时可中途跳出

## 核心 7 问（默认全问）

### Q1：一句话定位

> 用一句话告诉别人你的项目是干什么的？（中文 ≤30 汉字 / 英文 ≤120 字符）

**type**：free-text + inspiration（启发候选不强推）

候选启发（让用户参考但不强推）：
- A. 品类定义型："X is the [新品类] for [人群]"
- B. 结果承诺型："Build [结果] in [时间]"
- C. 身份共鸣型："For [自我认同]"
- D. 拟人/隐喻型："Like [熟悉事物] for [新场景]"
- Other：自由输入

### Q2：目标用户

> 谁会装这个项目？

候选：
- A. 开发者（前端 / 后端 / 全栈 / 运维）
- B. AI / ML 工程师
- C. 设计师 / 产品经理
- D. 终端用户（非技术）
- E. 企业团队 / 决策者
- Other / 多选

### Q3：核心价值（JTBD）

> 用户用了你的项目能完成什么 job？避免什么痛？

让用户写一段 2-3 句话的 PAS：
- 当前他们在 [场景] 想做 [事情]
- 现状是 [痛点]
- 你的项目让 [job] 变成 [新状态]

### Q4：差异化

> 和最像的 1-2 个竞品/替代品比，你的独特之处？（一句话）

如果用户答"没有竞品"，引导："那如果用户没用你的项目，他们今天怎么解决这个问题？"

### Q5：使用场景

> 列 2-3 个最典型的使用场景。（每个 1-2 句话）

用于生成 "Use cases" 段。

### Q6：信任锚

> 你有哪些可以拿来用的信任信号？（多选）

候选：
- A. 大客户 / Adopters（公司名）
- B. 名人 / KOL testimonial
- C. Benchmark 数字 / 性能对比
- D. 用户量级（stars / downloads / DAU）
- E. 奖项 / 排行榜（Trendshift, ProductHunt 等）
- F. 一时还没有，留空
- Other

如选 A-E，追问具体内容（可贴链接 / 数字 / 引言）。

### Q7：访客主路径 CTA

> 你最希望访客读完 README 后做什么？（单选）

候选：
- A. 装上试用（local install）
- B. 试线上 demo / playground
- C. Star + watch
- D. 加群 / 加 Discord
- E. 提 PR / 贡献
- F. 联系商业版 / 试用 Cloud

这决定了 hero CTA 的主按钮文案。

## 附加可问（按场景触发）

### 双语策略（仅当扫描识别为英文项目或用户说要国际化）
- 中文优先（M1）/ 英文优先（M2）/ 多语言（M3）/ 单文件中英对照（M4）

### 国内特有元素（仅当用户在国内 / 项目面向国内用户时问）
- 是否有飞书/微信/QQ 群？是否要放二维码？
- 是否在 ModelScope / WiseModel / OpenXLab 同步？
- 是否有 Bilibili 演示视频？
- 是否提供国内云一键部署（阿里云 / Sealos / Zeabur）？
- 是否有整合包（Windows 7z 一键启动）？

### 商业化（仅当扫描识别有 Cloud / Enterprise 文件夹）
- 是否有 Cloud / SaaS 版？
- 是否有 Enterprise / 商业版？
- 是否在招聘？

### 视频演示
- 有没有 30 秒-1 分钟的 demo 视频？（YouTube / Bilibili / 自托管）
- 如果没有，要不要在图片任务清单里建议录一个？

### 架构复杂度（仅当扫描识别 archetype 是 B 基础设施型 或 D 新品类教育型）
- 是否需要架构图？
- 已有的话给路径 / 没有的话需不需要 mermaid 自动生成？

## `--quick` 模式按需取问（最多 5 个）

按以下优先级取，命中即问，未命中即跳过：

**P0（核心，几乎都问）**：
1. **一句话定位**（Q1）
2. **目标用户 + 核心目的**（Q2 + Q3 合并为一句）

**P1（条件触发）**：
3. **主路径行动**（Q7，仅当无法从项目类型推断默认行动）
4. **差异化**（Q4，仅当用户/现有 README 提到"类似 X"）
5. **典型使用场景**（Q5，仅当 P0 答案抽象，缺具体场景）

**`--full` 在以上 5 题之外可加（最多到 7）**：
6. **信任锚**（Q6）
7. **双语 + 国内特有元素**

**用户选"全用默认/跳过"**：0 个问题。所有字段走默认值后备（详见 SKILL.md §2.4），在 REVIEW 阶段以 ⚠️ 标记，让用户决定是否定稿。

## 提问的语气示例

不要这样：
> 请问您的项目的 unique value proposition 是什么？

要这样：
> 假设你只能用一句话告诉别人你的项目，你会怎么说？写得难听点也没关系，先讲清楚。
