# templates/

每种 archetype 的中英双版骨架。生成时按选定的 archetype 加载对应模板，用 INTERVIEW 的回答填充。

## 文件清单

- `archetype-A-dev-tool.md` — 开发者工具型骨架（中 + 英）
- `archetype-B-infrastructure.md` — 基础设施/平台型骨架（中 + 英）
- `archetype-C-consumer-tool.md` — 消费/创作者工具型骨架（中 + 英）
- `archetype-D-new-category.md` — 新品类教育型骨架（中 + 英）
- `archetype-E-endorsement-first.md` — 第三方背书优先型骨架（中 + 英）
- `_universal-blocks.md` — 通用区块（contributing / license / domestic-community / star-history）
